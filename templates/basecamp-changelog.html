Changelog

Every release, newest first. Driftwood follows semantic versioning; patch releases are bug fixes only.

2026-06-30 · v4.2.0

Pinned deploys for domains

driftwood domains add now accepts --pin <hash>, so a domain can point at a specific deploy instead of always tracking the latest one. Useful for staged rollouts.

2026-05-14 · v4.1.2

Fix: driftwood logs dropping lines under load

Log streaming buffered incorrectly above roughly 200 requests per second, silently dropping lines instead of backpressuring. Fixed by switching the stream to a bounded channel with an explicit drop counter reported in the CLI.

2026-04-02 · v4.1.0

Secret environment variables

driftwood env set --secret stores a value encrypted at rest and omits it from driftwood env list output. Existing plain variables are unaffected.

2026-02-20 · v4.0.0

Config file replaces flags-only setup

Introduces driftwood.json. Projects without one keep working exactly as before — this is additive, not a breaking change, despite the major version bump for the new regions format.

2025-11-08 · v3.6.1

Fix: certificate renewal race on multi-domain projects

Projects with more than one attached domain could hit a renewal race that left one domain briefly unencrypted. Renewals are now serialized per project.

2025-09-01 · v3.6.0

Initial public release

Deploy, domains, logs, and env — the four commands most projects need on day one.
