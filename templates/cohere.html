Questions teams actually ask

Do we have to rewrite our event tracking?

No. If you already send events to a common analytics SDK, Vectorline reads the same stream. The deploy marker is the only new piece, and it's one webhook call from CI.

What counts as a seat?

Anyone who logs in to build or view a dashboard. Read-only links shared with stakeholders outside your org don't count and don't need an account.

Can we self-host the ingest pipeline?

Scale plans can point the SDK at a regional ingest endpoint we run for you, keeping raw events in-region. Full self-hosting isn't offered — we'd rather run it well for everyone.

What happens to our data if we cancel?

Every panel exports to CSV or a saved SQL query before you go. Raw event data is retained for 30 days after cancellation in case you change your mind, then deleted.
