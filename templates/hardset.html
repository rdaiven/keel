The block

Four phases, three weeks each. Every phase ends with a test set so the next one is loaded off real numbers, not a guess.

  1. Weeks 1–3

    Base. Volume goes up, weight stays conservative. The goal is groove, not a max — you'll want to add weight early. Don't.

  2. Weeks 4–6

    Build. Sets drop, load climbs. This is where the program starts to feel like work instead of practice.

  3. Weeks 7–9

    Peak. Singles and doubles at real weight. Sleep and food matter more here than any set on the page.

  4. Weeks 10–12

    Test. A planned taper into a new max on all three lifts, in week 12 — the number the whole block was for.
