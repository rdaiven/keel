Sections · Social proof

Six ways to let other people say it — quotes, names, numbers. Same rules as the main sections page: every pattern below is rendered as a real full-bleed band, with its exact markup underneath, and it re-renders in whatever tokens the design system page gives you.

Copy inside the sections is placeholder — the same fictional harbor-town businesses — so what you paste reads like a page, not like a template.
